# タイマー・アラームアプリケーション 要求仕様書

## 1. 概要

以下の機能を持つタイマー・アラームアプリケーションを作成する。
本アプリケーションは、ブラウザ上で動作し、**タイマー機能・アラーム機能** を実行できる。
本機能は同一ページにてタイマー・アラームの機能を切り替えて利用が可能。

---

## 2. 対象環境

- 使用言語: TypeScript
- 使用ツール: Vite, VSCode
- 動作環境: Google Chrome 最新版, Microsoft Edge 最新版
- データ保存: ローカルストレージ

---

## 3. 共通仕様

### 3.1 モード切替

- アプリケーション起動時はタイマーモードを表示する
- タイマーモードとアラームモードを切り替えられる
- モード切替は同一画面内で行う
- モード切替時にアプリケーションの再読み込みは行わない
- モード切替時も各モードの状態を保持する（例：タイマー実行中にアラームモードへ切り替えても、タイマーのカウントダウンは継続される）

### 3.2 データ保存

- アラーム設定情報(4.2.1)およびタイマー設定履歴(4.1.7参照)は保存ができる
- ブラウザを閉じても保持される
- アプリ起動時に自動的にタイマー設定・アラーム設定情報読み込む
- データの読み込みに失敗した場合は空の状態（履歴なし）として起動する

### 3.3 音声再生（鳴動キュー方式）

- タイマー終了時にアラーム音を再生する
- アラーム発火時にアラーム音を再生する
- 複数の対象がRinging状態の場合でも、再生する音声は1つのみとする
- 音声を再生する対象は鳴動キュー方式で管理し、先頭の対象のみ音声を再生する
- 鳴動キューにはアラーム（Ringing状態）とタイマー終了（Ringing状態）の両方が追加される
- 鳴動キューの並び順は発火の検出順（時刻順）とする
- タイマーとアラームが同時に発火した場合は、発火の検出順にキューへ追加する
- 鳴動キューの先頭がキューから除外された場合（Snoozing移行・停止・自動停止）、キュー内の次の対象の音声を再生する
- タイマーはスヌーズ機能がないため、鳴動キューから除外された場合は再追加されない
- ここでいう「鳴動開始」とは、対象の音声再生が始まった時点を指す（Ringing状態になった時点ではない）

### 3.4 音声停止

- ユーザーが音声の停止ボタンを押さない限り音声は停止されない
- ただし、鳴動開始から1分経過した場合は自動的に音声を停止する
- タイマー鳴動中に他のアラームが発火した場合も、停止ボタンを押すまでは鳴動状態を維持する
- Ringing状態のアラームは個別に停止可能とする
- 停止ボタン押下時は、対象のアラームをEnabled状態に戻す
- タイマー鳴動中はタイマー画面の停止ボタンで停止する
- ポップアップ通知上でも停止・スヌーズ操作が可能とする（3.5参照）
- 音声停止の自動判定（1分経過）は、対象の音声再生が始まった時点から計測する

### 3.5 ポップアップ通知

- 非表示中のモードで鳴動が発生した場合、ポップアップ通知を最前面に表示。
- ポップアップ通知は、他のモーダル表示中や操作中でも最前面に即座に表示される
- ポップアップ通知には以下の情報と操作ボタンを表示する

**アラーム発火時のポップアップ:**

```
━━━━━━━━━━━━━━━━━━━━━━━
⚠ アラームが鳴動中です
07:00
 [停止] [スヌーズ]
━━━━━━━━━━━━━━━━━━━━━━━
```

**タイマー終了時のポップアップ:**

```
━━━━━━━━━━━━━━━━━━━━━━━
⏰ タイマーが終了しました
設定時間 00:05:00
[停止]
━━━━━━━━━━━━━━━━━━━━━━━
```

- ポップアップ上の操作ボタンの動作は以下の通りとする
  - **[停止]**: 対象の鳴動状態を停止する（アラームはEnabled状態、タイマーはIdle状態に戻る）。操作後、ポップアップは自動的に閉じる
  - **[スヌーズ]**（アラームのみ）: 対象のアラームをスヌーズ状態へ移行する。操作後、ポップアップは自動的に閉じる
- ポップアップは複数の鳴動が発生した場合、鳴動ごとに表示する
- ポップアップは対象が鳴動キューに追加された時点で表示する（音声再生開始前の待機中であっても表示する）
- 複数のポップアップが同時に表示される場合、重ならないように表示する
- ポップアップは表示開始から1分経過した場合、自動的に閉じる

## 4. 機能仕様

### 4.1 タイマー機能

#### 4.1.1 タイマー設定

- 時間、分、秒を入力してタイマーを設定できる
- 入力方法はスライダーで選択、またはテキストボックスに直接入力可能
- 初期表示は00:00:00とする

| 項目 | 範囲  |
| ---- | ----- |
| 時間 | 0～23 |
| 分   | 0～59 |
| 秒   | 0～59 |

- 範囲外の数値がテキスト入力された場合、以下のルールで補完する
  - 各項目の上限値を超える数値 → 上限値に補完（例：時間に99→23、分に99→59）
  - 小数を含む数値 → 切り上げて整数に補完（例：0.3→1、1.5→2）
  - 上限値を超えた小数 → 上限値に補完（例：時間に99.9→23）
  - 負の値 → 絶対値として扱い、さらに上限値を超える場合は上限値に補完（例：-1→1、-99→23）
- 00:00:01以上の時間が設定されない限り、「開始」ボタンは押下不可とする

#### 4.1.2 タイマー開始

- 開始ボタン押下でカウントダウンを開始する
- 残り時間を1秒単位で更新する
- 実行中は設定値の編集を不可とする
- 開始時に、設定した時間（時・分・秒）がタイマー設定履歴として自動保存される

#### 4.1.3 タイマー一時停止

- 一時停止ボタン押下でカウントダウンを停止する
- 停止時点の残り時間は保持する

#### 4.1.4 タイマー再開

- 一時停止中に再開ボタンを押下するとカウントダウンを再開する

#### 4.1.5 タイマーキャンセル

- キャンセルボタン押下でタイマーを停止し、残り時間を初期値へ戻す

#### 4.1.6 タイマー終了

- 残り時間が0になった場合、タイマー鳴動状態となる
- タイマー終了時は鳴動キューに追加され、キュー先頭の場合のみアラーム音を再生する
- アラーム音は停止ボタンを押さない限り、鳴り続ける
- ただし、鳴動開始から1分経過した場合は自動的に音声を停止し、タイマー状態を止める
- 鳴動キューで待機中（先頭でない）の場合も、鳴動開始から1分経過した場合は自動的に音声を停止し、タイマー状態を止める
- タイマーにスヌーズ機能はない
- タイマーが鳴動キューに追加された際、非表示モード（アラームモード表示中）の場合はポップアップ通知を表示する（3.5参照）

#### 4.1.7 タイマー設定履歴

- タイマーを開始した際に、設定した時間（時・分・秒）が履歴として自動保存される
- 保存可能件数は最大5件とする
- 同じ時間の履歴は重複して保存されない（既に同じ時間の履歴が存在する場合、新たには保存しない）
- 履歴が5件保存されている状態で新しい履歴を保存する場合、最も古い履歴が削除され、新しい履歴が追加される
- 履歴はLocalStorageに保存され、ブラウザを閉じても保持される
- 「タイマー設定履歴」ボタンを押下すると履歴一覧がモーダル表示される
- 履歴一覧から選択すると、即座にタイマー設定値に反映される
- 設定値反映後、モーダル画面に「設定しました」のログを表示する（ログは数秒で自動消去される）
- アプリ初回起動時は履歴は空の状態とする

#### 4.1.8 エラー処理

- 時間、分、秒がすべて0の場合は開始できない
- 数値範囲外入力は補完処理を行う

### 4.2 アラーム機能

#### 4.2.1 アラーム登録

- 時間および分を指定してアラームを登録できる
- アラームの設定画面はモーダル表示とする
- 24時間表記で入力する
- 入力方法はスライダーで選択、またはテキストボックスに直接入力可能
- 登録可能件数は最大5件とする
- 既に5件登録済みの場合、新規登録ボタンは無効化する

| 項目 | 範囲  |
| ---- | ----- |
| 時間 | 0～23 |
| 分   | 0～59 |

- 範囲外の数値がテキスト入力された場合、以下のルールで補完する
  - 各項目の上限値を超える数値 → 上限値に補完（例：時間に99→23、分に99→59）
  - 小数を含む数値 → 切り上げて整数に補完（例：0.3→1、1.5→2）
  - 上限値を超えた小数 → 上限値に補完（例：時間に99.9→23）
  - 負の値 → 絶対値として扱い、さらに上限値を超える場合は上限値に補完（例：-1→1、-99→23）
- 既に同じ時刻のアラームが登録されている場合はエラーとし、登録できない

#### 4.2.2 アラーム保存

- 登録したアラームはLocalStorageへ保存する
- ブラウザを閉じた後も保持する
- アプリ起動時に保存済みアラームを読み込む
- アラーム一覧は時刻順（昇順）にソートして表示する

#### 4.2.3 アラーム有効化

- 登録済みアラームを有効化できる
- 有効化されたアラームのみ発火対象とする

#### 4.2.4 アラーム無効化

- 登録済みアラームを無効化できる
- 無効化されたアラームは発火対象外とする
- 無効化対象のアラームがRinging状態またはSnoozing状態の場合、無効化不可。

#### 4.2.5 アラーム削除

- 登録済みアラームを削除できる
- 削除時に確認ダイアログを表示し、ユーザーが「OK」を選択した場合のみ削除を実行する
- 削除したアラームはLocalStorageからも削除する
- 削除対象のアラームがRinging状態またはSnoozing状態の場合、削除不可。

#### 4.2.6 アラーム発火（鳴動キュー方式）

- 有効化されたアラームは、現在時刻の時と分が設定時刻と一致した場合、状態がRingingに遷移する
- Ringing状態のアラームは鳴動キューに追加され、時刻順（昇順）に管理される
- 音声を再生するのは鳴動キューの先頭の対象のみとする
- キュー先頭が鳴動している状態で他のRinging状態のアラームがある場合は、音声は鳴らさず画面上で発火済みであることが把握できるように表示する
- Ringing状態のアラームは鳴動開始から1分経過で自動的にスヌーズ状態へ移行する
- 自動スヌーズもスヌーズ最大3回にカウントされる
- Ringing状態のアラームは個別にスヌーズ・停止操作が可能
- アラームが発火した際、非表示モード（タイマーモード表示中）の場合はポップアップ通知を表示する（3.5参照）

#### 4.2.7 アラームの繰り返し

- アラームは有効状態を維持している限り、毎日同じ時刻に発火する（毎日繰り返し）
- アラーム発火後（Ringing状態）に個別停止ボタンを押下すると、対象のアラームのみ有効状態（Enabled）に戻り、翌日以降も同じ時刻に発火する
- 個別停止されたアラームは発火対象から除外されず、翌日も同じ時刻に発火する

#### 4.2.8 スヌーズ機能

- 各Ringing状態のアラームは、個別にスヌーズ操作が可能
- 画面上の各アラーム行にスヌーズボタンを設け、押下すると該当アラームのみスヌーズ状態へ移行する
- スヌーズ時間は5分とする
- スヌーズ状態では音声は停止する
- スヌーズ状態では以下の情報を表示し、ユーザーがスヌーズ中であることを視認できるようにする
  - 残りスヌーズ時間（例：あと4:32）
  - スヌーズ回数（例：スヌーズ 1/3回）
- スヌーズボタン押下時、対象のアラームがスヌーズ状態へ移行後、画面上に次のRinging状態のアラームが存在する場合は、自動的に次のアラームが選択状態となり音声を再生する
- 他にRinging状態のアラームが存在しない場合は、音声は停止したままとなる
- スヌーズ時間経過後、該当アラームは再度Ringing状態へ戻り、音声再生対象となる
- スヌーズ再発火時、非表示モード（タイマーモード表示中）の場合はポップアップ通知を表示する（3.5参照）
- スヌーズは最大3回まで繰り返し可能とする
- 3回目のスヌーズ終了後は、アラームは有効状態（Enabled）に戻り、翌日以降も同じ時刻に発火する
- 鳴動開始から1分経過による自動停止後も、スヌーズ状態へ移行する

#### 4.2.9 エラー処理

- 登録件数が5件を超える場合は登録できない
- 既に同じ時刻のアラームが登録されている場合は登録できず警告する
- 補完後も不正な時刻の場合は登録できず警告する

## 5. 操作例

### 5.1 タイマー利用例

| 操作               | 表示                               |
| ------------------ | ---------------------------------- |
| 1時間30分0秒を設定 | 01:30:00                           |
| 開始               | 01:29:59（履歴に01:30:00が保存）   |
| 一時停止           | 01:20:15                           |
| 再開               | 01:20:14                           |
| 時間経過           | 00:00:00                           |
| 終了               | アラーム音再生                     |
| 1分経過            | 自動停止、Idleに戻る               |
| 履歴ボタン押下     | モーダルで履歴一覧を表示           |
| 履歴から選択       | 設定値に反映、「設定しました」表示 |

### 5.2 アラーム利用例

| 操作                          | 結果                                                           |
| ----------------------------- | -------------------------------------------------------------- |
| 07:30登録（モーダル画面）     | アラーム一覧へ追加（時刻順にソート）                           |
| 同じ07:30を登録               | エラー表示、登録不可                                           |
| 有効化                        | 毎日07:30に発火するよう設定                                    |
| 07:30到達                     | アラーム音再生                                                 |
| 07:30の[スヌーズ]押下         | 07:30のみスヌーズ→音停止、残り時間・回数表示（スヌーズ 1/3回） |
| スヌーズ2回目                 | 5分後に再び鳴動                                                |
| スヌーズ3回目                 | 5分後に再び鳴動、終了後Enabledに戻る                           |
| 07:30の[停止]押下（個別停止） | 07:30のみ停止(Enabled)→翌日も有効状態を維持                    |
| 1分経過                       | 自動停止、スヌーズ状態へ移行                                   |
| 無効化                        | Ringing/Snoozing状態の場合は無効化不可                         |
| Ringing中に削除               | 削除不可                                                       |
| 削除                          | 確認ダイアログ → OKで削除                                      |
| **4:00, 4:01, 4:02 連続設定** | **4:00発火→4:01,4:02もRinging状態で一覧表示**                  |
| 4:00の[スヌーズ]押下          | 4:00のみスヌーズ→キューから除外→4:01の音声再生                 |
| 4:01の[停止]押下（個別停止）  | 4:01のみ停止(Enabled)→キューから除外→4:02の音声再生            |
| 4:02の[スヌーズ]押下          | 4:02のみスヌーズ→キューから除外→Ringingなしのため音声停止      |

## 6. 各機能の定義一覧

| 項目                     | 内容                                                                 |
| ------------------------ | -------------------------------------------------------------------- |
| タイマー時間             | 0～23時間                                                            |
| タイマー分・秒           | 0～59                                                                |
| アラーム件数             | 最大5件                                                              |
| タイマー設定履歴件数     | 最大5件                                                              |
| アラーム時刻             | 24時間表記                                                           |
| アラーム発火条件         | 時・分の一致                                                         |
| アラーム表示順           | 時刻順（昇順）                                                       |
| 発火音声方式             | 鳴動キュー方式（先頭の対象のみ音声再生）                             |
| 鳴動キュー対象           | アラーム（Ringing状態）・タイマー終了（Ringing状態）                 |
| スヌーズ時の動作         | スヌーズしたアラームをキューから除外→次のRingingアラームの音声を再生 |
| スヌーズ時間             | 5分                                                                  |
| スヌーズ最大回数         | 3回                                                                  |
| 鳴動最大時間（アラーム） | 1分（経過後自動停止→スヌーズ状態へ移行）                             |
| 鳴動最大時間（タイマー） | 1分（経過後自動停止→Idle状態へ移行）                                 |
| ポップアップ通知         | 非表示モードで鳴動発生時に表示（停止・スヌーズ操作可能）             |
| データ保存               | LocalStorage                                                         |
| 動作単位                 | 1秒                                                                  |
